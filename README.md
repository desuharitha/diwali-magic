# Diwali Magic

A personalized Diwali greeting built with Canvas and Web Audio. The existing five scenes use a 9:16 composition with a layered courtyard, diyas, a rangoli, sky lanterns, and fireworks. All art, particles, and sounds are generated by the app.

## Create a greeting

Open the hosted creator page without a personalized fragment. Enter **From** and **To**, then select **Generate Greeting Link**. Use **Preview Greeting** to open the recipient view in a new tab, **Copy Link** to copy it, or **Share Greeting** for your device’s share menu. Browsers without native sharing use the clipboard flow.

The link opens with the personalized greeting and hides the creator interface. The names are ordinary URL-fragment text, visible to anyone with the link. Keep sensitive information out of names. The recipient view is a presentation mode, and the creator page is accessible at the site's base address.

## Play the greeting

- Move the pointer or drag a finger for sparkles. The first user gesture enables audio. Use **Sound** to mute it.
- Tap the diyas to light them, reveal the rangoli, then release lanterns into the sky.
- In the finale, the first tap launches a firework at that point and starts a crescendo. More taps add fireworks. A softer ambient display continues after the grand finale until **Stop fireworks**, **Replay show**, or a scene change.
- Use the arrow buttons, number tabs, or keyboard Left and Right to choose a scene. Space or Enter activates the focused control or the scene action. **Replay greeting** starts the greeting again.

On a personalized link, **Tap to begin** starts all five acts. The house lights up, diyas ignite, the rangoli appears, lanterns rise, and the fireworks start automatically. Replay starts the whole journey again, Pause holds the current moment, and Exit returns to the invitation. Creator mode keeps scene-by-scene preview controls. Supported Android devices may vibrate briefly for user-triggered bursts. Device settings, browser support, and reduced-motion preferences affect vibration. Audio starts after an eligible gesture. The app reduces drawing resolution and particle density on smaller or slower devices.

## Run locally and download MP4

Install Python 3.10 or later and a build of FFmpeg with AAC and libx264 or libopenh264. Put FFmpeg on your PATH or set the `FFMPEG` environment variable to its executable. Then run:

```sh
python server.py
```

Open the address printed in the terminal, normally http://127.0.0.1:8765. The interactive greeting works without FFmpeg. Select **Download MP4** in the local creator to export a personalized film with synced sound and automatic fireworks.

Export is 30 FPS, defaults to **1080 × 1920**, and also supports **720 × 1280** and **2160 × 3840**. Choose a 35-, 47-, or 60-second film, or a 13-second finale clip. Use 720 × 1280 for quicker previews. Keep the local creator open while it renders.

## Batch export

Install Node.js 22 or later and Chrome, Chromium or Edge. The batch tool uses a temporary browser profile. Set `CHROME` to the browser executable if automatic detection misses it.

```sh
python batch.py sample.csv --output videos
python batch.py sample.csv --output previews --width 720 --duration finale
```

Use a UTF-8 CSV with `From,To` headers. The script skips duplicate pairs and caches renders in the output folder’s `.diwali-cache` directory. Changing the names, export settings, browser, encoder, or renderer invalidates the relevant cache.

To run the browser smoke test, start the local server and run:

```sh
node smoke.mjs "<browser executable>" http://127.0.0.1:8765
```

## Hosting

Publish the contents of `web/` together on a static HTTPS host. All site assets use relative paths, so the greeting also works under a repository subpath. Use a standalone host or a custom domain you control for links that omit the GitHub username and repository. The source archive includes the local tools separately from the web files.

The site uses no database, paid API, or per-greeting AI inference. The interactive rendering runs on the visitor’s device. Hosting and bandwidth depend on the selected provider. Video encoding runs locally.
